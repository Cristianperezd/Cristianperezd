## Featured project

**[TFG-Snake](https://github.com/Cristianperezd/TFG-Snake)**: Bachelor's thesis. Snake built in Pygame to compare search agents (GBFS, A\*) against reinforcement learning (PPO with Stable Baselines 3). Over 50 games, A\* averaged 78 points versus 21 for PPO. Currently being revisited with versioned releases, tests and CI.
